# Age rating answers

> Draft. Answer each store questionnaire honestly for the build you submit. The recommendation below assumes the current features: no user-to-user communication, no web browsing, no purchases, no ads, an on-device AI that answers astrology questions.

## Recommendation

| Store | Expected rating | Notes |
|---|---|---|
| Apple App Store | **13+** (choose it with the age-rating override if the questionnaire computes lower) | The AI writes free text about relationships, marriage, health worries, grief and career stress. It is filtered by the app's safety routes, but it is still generated text. 13+ also matches the privacy policy ("not directed at children under 13"). |
| Google Play (IARC) | Likely **Everyone / PEGI 3 / 3+**, possibly **Teen / PEGI 12** depending on the AI answer below | Play target audience: 18+ (or 13+), never under 13. |

## Apple questionnaire (2025 format)

| Question | Answer |
|---|---|
| Cartoon or fantasy violence | None |
| Realistic violence | None |
| Prolonged graphic or sadistic violence | None |
| Profanity or crude humour | None |
| Mature or suggestive themes | **Infrequent / mild** (relationship, marriage and grief topics in AI answers) |
| Horror / fear themes | None |
| Medical or treatment information | **Infrequent / mild**: health is one astrology life area; the app gives no medical advice and says so. If the questionnaire treats this as "medical information", answer Infrequent. |
| Alcohol, tobacco or drug use or references | None |
| Simulated gambling | None |
| Sexual content or nudity | None |
| Graphic sexual content and nudity | None |
| Contests | No |
| Unrestricted web access | **No** (links open specific licence pages in the system browser only) |
| User-generated content | **No** (nothing is shared between users; sharing a card goes through the system share sheet) |
| Messaging and chat (with other people) | **No** (the chat is with an on-device AI, not with people) |
| Advertising | No |
| Parental controls / age assurance | No |
| Does the app use AI to generate content? | **Yes**, on-device text generation (if asked) |

Astrology itself is not a rating category. Apple may still review astrology apps under guideline 4.3 (saturated categories); see `review-notes.md`.
